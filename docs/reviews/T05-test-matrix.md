## Explicit NOT RUN Scope (Documented Limits)
1. **Multi-Matter Role Constraints:** Assigning client and opponent roles simultaneously across multiple active matters belongs to Task T06 (`MatterParty`); T05 validates party data in isolation.
2. **Document File Uploads & ClamAV:** File attachments and malware scanning are excluded in T05 per ADR 0003 and Roadmap T05 scope.
3. **Physical-Device Auditory Screen Readers:** Verification is conducted via DOM tree inspection, ARIA semantics, and keyboard accessibility; real physical-device auditory testing with NVDA/JAWS/VoiceOver is an external pilot limit.
4. **Production Deployment & Real Client Data:** All verification is conducted strictly with synthetic records and test keys in disposable environments.
